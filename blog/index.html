Selamat Datang di My Home Server

13 Juni 2026

STB B860H dengan eMMC rusak berfungsi penuh sebagai server rumahan. Berkat Docker, semua layanan berjalan di container terisolasi tanpa dependency conflict.

Spesifikasi:

  • SOC: Amlogic S905X (ARM Cortex-A53)
  • RAM: 1 GB DDR3 + ZRAM 512MB + SWAP 1GB
  • Penyimpanan: SD Card
  • Sistem: Armbian + Docker

Layanan Berjalan di Docker

13 Juni 2026
  • Dashboard Monitor - Flask container (port 8080)
  • FileBrowser - filebrowser/filebrowser (port 8081)
  • CCTV NVR - ccrisan/motioneye (port 8765)
  • Cloudflare Tunnel - cloudflare/cloudflared
  • Terminal - tsl0922/ttyd + btop (port 7681)

Mengelola Container

13 Juni 2026

Semua service dikelola via docker-compose di /opt/homeserver:

  • docker-compose ps - lihat status container
  • docker-compose logs -f - lihat log real-time
  • docker-compose restart [service] - restart service tertentu
  • docker-compose pull - update semua image
